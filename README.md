# coverflow-slider

یک اسلایدر سه‌بعدی به سبک Cover Flow (مثل iTunes قدیمی) با HTML/CSS/JS خالص.

## امکانات
- افکت سه‌بعدی: کارت وسط جلو، کارت‌های کناری با چرخش و بازتاب
- حرکت با دکمه‌های قبل/بعد، کلیک روی کارت‌ها، و کلیدهای ← →
- کاورها از یک آرایه‌ی داده ساخته می‌شوند (گرادیان رنگی، بدون نیاز به عکس خارجی)

## اجرا
فایل `index.html` را در مرورگر باز کنید (یا یک وب‌سرور ساده مثل `python3 -m http.server`).
